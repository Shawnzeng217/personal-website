我的开发工具配置

📅 2026-01-15 🏷️ 工具,效率

开发工具配置 🛠️

编辑器

VS Code 是我的主要编辑器，配合以下插件：

  • GitLens - 代码历史追溯
  • Error Lens - 错误提示增强
  • Prettier - 代码格式化
  • Markdown All in One - Markdown 编辑

终端

使用 iTerm2 + Oh My Zsh：

# 安装 Oh My Zsh
sh -c "$(curl -fsSL https://raw.githubusercontent.com/ohmyzsh/ohmyzsh/master/tools/install.sh)"
安装插件

source $ZSH/custom/plugins/zsh-autosuggestions
source $ZSH/custom/plugins/zsh-syntax-highlighting

包管理

  • Homebrew - macOS 包管理
  • nvm - Node.js 版本管理
  • pyenv - Python 版本管理

AI 助手

  • OpenClaw - 本地 AI 助手框架
  • Claude - 主力对话 AI

其他工具

  • Raycast - 快速启动器
  • Notion - 笔记管理
  • Obsidian - 知识库
