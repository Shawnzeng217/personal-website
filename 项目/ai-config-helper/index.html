AI 助手配置助手 ⚡

项目简介

一个交互式命令行工具，帮助用户快速配置 AI 助手开发环境。

功能特性

  • 🎯 自动检测系统环境
  • 🔧 一键安装依赖
  • 📦 支持多平台 (macOS/Linux)
  • 🔄 增量更新支持

使用方法

# 安装
git clone https://github.com/Shawnzeng217/ai-config-helper.git
cd ai-config-helper
chmod +x install.sh
./install.sh
运行

ai-config --wizard

配置选项

  • 包管理器 (Homebrew/npk/apt)
  • 编辑器选择 (VS Code/Neovim/Emacs)
  • AI 框架选择 (OpenClaw/LangChain/LlamaIndex)
