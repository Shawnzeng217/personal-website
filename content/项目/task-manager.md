# 个人任务管理系统 🚀

## 项目简介

这是一个用 AI 辅助的任务管理工具，帮助我更好地规划和管理日常任务。

## 技术栈

- **前端**: React + TailwindCSS
- **后端**: Node.js + Express
- **数据库**: SQLite
- **AI**: OpenAI API

## 主要功能

- [ ] 智能任务分类
- [ ] 自动优先级排序
- [ ] 时间估算建议
- [ ] 进度追踪
