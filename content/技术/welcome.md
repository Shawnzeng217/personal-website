# 欢迎 👋

这是一个使用 Markdown 管理的静态网站。

## 特性

- **Markdown 管理** - 用熟悉的语法写内容
- **自动生成** - 一键构建整个网站
- **多层级分类** - 支持无限层级的内容组织
- **响应式设计** - 完美适配各种设备

## 快速开始

```bash
# 安装依赖（如果需要）
pip install -r requirements.txt

# 构建网站
python3 scripts/build.py

# 本地预览（需要安装 http.server）
cd public && python3 -m http.server 8080
```
